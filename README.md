## 📦 包含的技能

### 1️⃣ pharma-eval — 医药项目深度投资评估

**关键词：** `@项目评估`

当你拿到一个项目的 BP、尽调报告、临床数据或其他材料时，用这个技能一键生成一份 **基金合伙人级投资备忘录**。

包含 **15个章节** 的完整分析框架：
| 章节 | 内容 |
|------|------|
| 一 | 项目核心结论（先给结论，后给分析） |
| 二 | 项目概况梳理 |
| 三 | 创始团队与组织能力判断 |
| 四 | 技术与产品竞争力分析 |
| 五 | 临床开发与注册路径分析 |
| 六 | 市场空间与商业化分析 |
| 七 | 竞争格局与对标分析 |
| 八 | 知识产权与壁垒分析 |
| 九 | 生产、CMC、供应链与落地风险 |
| 十 | 财务、融资与资本效率分析 |
| 十一 | 估值分析与投资回报测算 |
| 十二 | 退出路径分析 |
| 十三 | 投资风险清单（≥10条，按优先级排序） |
| 十四 | 最该补充尽调的问题清单 |
| 十五 | 最终投资建议 |

**使用示例：**
```
上传BP后说：@项目评估
或：评估这个项目
```

### 2️⃣ pharma-asset-strategist — 新药价值评估模型 3.0

**关键词：** 管线评估、竞争情报、药物发现、新药审视

这是一个 **制药竞争情报与战略审视官** 角色技能。通过四象限压力测试，对你的管线资产进行系统性审视：

| 象限 | 维度 | 核心问题 |
|------|------|----------|
| 🧬 | 生物学与靶点 | 靶点验证、MoA、人类遗传学、转化医学 |
| ⚗️ | 药物形式与化学 | 分子设计、PK/PD、CMC瓶颈 |
| 🏥 | 临床与监管 | 试验设计、患者分层、FDA/EMA路径 |
| 💰 | 商业与市场 | 竞争格局、SoC演变、支付方动态 |

**三级创新分类：**
- **Level 1.0 Me-Too（微创新）** — 赛道拥挤，技术成功率高但商业风险极大
- **Level 2.0 优化者** — 靶点已验证但具差异化，需完美临床执行
- **Level 3.0 先驱者** — 全新靶点/机制，高风险但天花板极高

**交互方式：** 模块会按"生物学→药物形式→临床→商业"顺序逐个提问，完成至少3轮问答后生成完整战略报告。

## ⚡ 快速安装

### 前提条件

你需要已安装 **Hermes Agent**（Nous Research 出品），Hermes 是一个支持插件式技能（Skill）的 AI 助手。

### 方式一：一键安装（推荐）

```bash
git clone https://github.com/<你的GitHub用户名>/<仓库名>.git
cd <仓库名>
chmod +x install.sh
./install.sh
# 重启 Hermes Agent 即可使用
```

### 方式二：手动安装

```bash
# 克隆仓库
git clone https://github.com/<你的GitHub用户名>/<仓库名>.git

# 复制到 Hermes Skills 目录
mkdir -p ~/.hermes/skills
cp -r pharma-eval ~/.hermes/skills/
cp -r pharma-asset-strategist ~/.hermes/skills/

# 重启 Hermes Agent
```

### 方式三：通过 npx openskills 安装（如支持）

```bash
npx openskills install https://github.com/<你的GitHub用户名>/<仓库名>
```

## 🧠 底层模型

- **pharma-eval** 默认使用 GPT-5.5 / GPT-5.4（最新GPT模型），通过 SkillFree 平台调用

如需切换模型，在调用时指定即可，如："用Claude分析这个项目"
